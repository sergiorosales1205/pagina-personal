# Landing Page Portafolio - Sergio Rosales Diego

Página de aterrizaje (Landing Page) de una sola página desarrollada como proyecto personal de un estudiante de **Diseño y Desarrollo de Software**.

## 📁 Archivos
- `index.html`: Estructura semántica única (Hero, Sobre Mí, Habilidades, Proyectos y Contacto).
- `css/styles.css`: Estilos personalizados con Flexbox, CSS Grid, Variables CSS y Modo Oscuro.
- `js/script.js`: Interactividad (desplazamiento suave, filtros, modal y menú móvil).
